# Поиск фильмов

Учебный дипломный проект для поиска фильмов и сериалов через Kinopoisk API. На сайте можно посмотреть подборку, найти фильм по названию, применить фильтры и открыть страницу с подробной информацией.

Деплой: [добавить ссылку]

## Функционал

- поиск фильмов;
- каталоги фильмов и сериалов;
- фильтрация по жанру, рейтингу, стране и году;
- пагинация каталога;
- карусели с карточками фильмов и кадрами;
- страница фильма с трейлером, кадрами и отзывами;
- тёмная тема;
- адаптивная вёрстка и бургер-меню.

## Технологии

- HTML5;
- CSS3;
- JavaScript (ES6+, модули);
- Fetch API;
- Kinopoisk API;
- Jest;
- Git/GitHub.
